# Spaced Repetition Learning Simulation

This example demonstrates a simplified spaced repetition learning system, a science-backed method for effective learning. It simulates how active recall and spaced repetition can improve memory retention. Users review flashcards, rate their recall, and the system dynamically schedules future reviews based on performance, mimicking how memory works.

## Language

`python`

## How to Run

1. Save the code as `active_learner.py`.
2. Run from your terminal: `python active_learner.py`
3. Follow the prompts to review flashcards and advance simulated days.
